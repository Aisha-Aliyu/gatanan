# Gatanan

An autonomous AI showrunner that turns African oral folktales into narrated short films.

## Status
In active development. See the build log for daily progress.

## Stack
- Backend: Python, FastAPI, Qwen Cloud (Alibaba Model Studio)
- Frontend: Next.js (coming)
- Models: Qwen3-Max, Qwen-Image, Wan, Qwen3-TTS
